## 🗂 Organização do repositório

Cada pasta possui um README com descrição, tecnologias, objetivos de aprendizagem, declaração de uso de IA e informações de publicação.

A **AT1** inclui os PDFs e as versões HTML do perfil pessoal e profissional. A **AT3** inclui o código da calculadora de IMC e instruções de execução local. A **AT4** apresenta o Pixel Club e a **AT5**, o Foco Digital, ambas com links para o site publicado e o repositório de código-fonte. A **AT2** possui documentação inicial a ser complementada.
